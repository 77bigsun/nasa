# 原任務流程中的月球計分

月球頁維持原本的 **選擇測試 → 選擇目標 → 比較地球地點**。任務卡片、地圖、排名列、證據抽屜、門檻控制與覆蓋分析沿用原設計，內部計算依據 2026-11-14 的月球方法 PDF 調整。

## 保留測試與權重

| 測試 | 內容 | 預設權重 |
|---|---|---:|
| M2 | 低太陽角光照與太陽能 | 0.183 |
| M3 | 長時間黑暗與極寒 | 0.429 |
| M4 | 陡坡與極端地形移動 | 0.280 |
| M6 | 冷陷冰資源探勘 | 0.108 |

M1 因缺少 1–5 公尺地球地形、且與 M4 地形條件重複而排除。M5 的現有資料無法有效區分驗證組別，缺資料的分數區間也彼此重疊，因此排除於計分之外；原定義與來源結果仍保留。

每項測試依 PDF 合成：

$$S=100\frac{\sum_i w_i c_i s_i}{\sum_i w_i c_i}$$

原網站維持 **0–1** 顯示刻度，因此 PDF 的 **40.8 分會顯示為 0.408**。選擇部分測試時重新正規化測試權重，也保留原本的自訂任務權重。團隊尚未提供特徵的重要度與不確定度數值，預設各為 1。

資料適配度 c 為：直接衍生資料 1.0、代理資料 0.6、文件判斷 0.3、缺資料 0。這不是統計信賴度；抽屜會顯示輸入值、相似度 s、適配度 c、特徵權重 w 及來源。

## 特徵與公式

| 測試 | 特徵及公式 |
|---|---|
| M2 | 春秋分正午高度角為 90 度減緯度絕對值，D 型錨點為 90／5 度；白天太陽高度低於 10 度的全年比例，錨點為 0／1。 |
| M3 | 最長黑暗的 D 型錨點為 12／120 小時；年最低 2 公尺氣溫為 0／−89°C；平均每日氣溫差為 10／40°C。 |
| M4 | 坡度直方圖先正規化，再計算 0–5、5–10、10–15、15–20、20–30、大於 30 度六箱交集；16 公里起伏採對數高斯，參考值 2477 公尺，σ＝ln 2。 |
| M6 | 年均溫 D 型錨點為 15／−55°C；年最高溫為 40／−20°C；文件冰凍土檢核為永凍土 0.4＋地下冰 0.3＋冷陷冰 0.3。 |

D 型為 `clip((x−b)/(t−b), 0, 1)`，負溫度錨點仍維持正確方向。起伏公式為 `exp(−0.5×[ln(x/μ)/σ]²)`；四捨五入的直方圖比例先正規化再計算交集。

## 所選目標與資料界線

M2／M3／M6 使用**共通的地球可達測試錨點**，不代表不同月球地點的實測條件相同。PDF 的 30 公尺網格／16 公里 M4 參考目前僅有 **Shackleton 連接脊**。選其他目標時，仍保留該目標身分，並將 M4 標為缺少參考；不替換成連接脊地形。先前 2 公里／100 公尺的地形產品範圍不同，不能直接補入此參考。

候選清單包含 12 個團隊 CSV 驗證點與 3 個 PDF 極區區域範例。天文特徵已依 365 日、每 10 分鐘取樣、−0.833 度日出門檻重算，未考慮地形遮蔽。氣候彙整為 2 公尺氣溫，僅作為地表熱測試代理量；尚未附原始氣候 API 回應與地形窗口。極區彙整經過四捨五入，也缺少若干特徵。冰凍土檢核為尚未核實的團隊文件判斷，c＝0.3，並非新驗證的含冰量測。

缺資料仍維持缺資料。排名可顯示現有證據的部分分數，但完整測試覆蓋須具備全部必要特徵；部分高分不能代表完整測試覆蓋或物理等同。覆蓋門檻用於此暫定模型，並非任務認證。

原本的敏感度按鈕現在會針對所選目標，檢查錨點／參考值 ±20% 及不同任務權重，顯示確定性情境中的前三名出現頻率，不當成覆蓋網路的蒙地卡羅樣本。

來源壓縮檔未包含 PDF 所述的全球 POWER／起伏格點，目前只有 15 個研究點，尚無全球熱度圖，也不能宣稱找出全球最佳地點。
