# 月球任務：先看月球適配，再看地球類比

月球入口顯示 **M2、M3、M4、M6** 四項任務。進入單一任務後，上半部列出十個月球地點的任務適配，下半部並排對照**最相似的三個地球新候選地與最不相似的三個地點**。沿用原網站的色彩、導覽、地圖、資料抽屜與語言切換；火星仍使用既有的觀測比較流程。

## 月球任務適配與地球相似度分開判讀

23:50 版公式原理文件依已發表研究，將月球地點分配到主要與次要任務。網站呈現為**優先評估、需條件確認、證據不足**。這是團隊的初步判斷，不是飛行安全或任務操作可行性的認證；沒有列入某項任務，也不代表已證明不可行。

新的交接資料已包含十個地點各自的 **30 公尺坡度分布與 16 公里起伏**。M4 直接使用所選地點自己的地形。M2、M3、M6 採共用的地球可達極端值作為錨點，因此切換月球地點時，這三項的地球排名相同；這不表示各月球地點的實際條件相同。

此頁採用交接資料的研究範圍座標，與先前觀測模型的研究點分開。連接脊沒有提供經度：保留報告緯度，地圖則明確採用有地理定位的 PGDA Site01 圖幅中心，不將兩者混稱為同一筆量測。

## 分數公式與修訂後的特徵權重

$$S=100\frac{\sum_i w_i c_i s_i}{\sum_i w_i c_i}$$

| 任務 | 特徵、權重 w 與適配度 c |
|---|---|
| M2 | 春秋分正午太陽高度角：w=0.30、c=1.0；低於 10° 的白天光照比例：w=0.70、c=1.0。 |
| M3 | 最長連續黑暗：w=0.50、c=1.0；年最低 2 公尺氣溫：w=0.35、c=0.6；氣溫日溫差：w=0.15、c=0.6。 |
| M4 | 30 公尺坡度直方圖：w=0.70、c=1.0；16 公里地形起伏：w=0.30、c=1.0。 |
| M6 | 年均溫：w=0.25、c=0.6；年最高溫：w=0.25、c=0.6；氣溫推估的永凍土與地下冰：w=0.50、c=0.3。 |

單向線性相似度為 `clip((x-b)/(t-b),0,1)`。M2 正午高度角的零分／滿分錨點為 90°／5°，低角度比例為 0／1；M3 黑暗為 12／120 小時，最低溫為 0／-89°C，日溫差為 10／40°C；M6 年均溫為 15／-55°C，最高溫為 40／-20°C。M6 推估值為 `0.4*[年均溫<=-2]+0.3*[年均溫<=-8]`，地球冷陷冰項為零。

M4 以六個坡度區間（0–5、5–10、10–15、15–20、20–30、超過 30°）的直方圖交集比較分布。起伏採 `exp(-ln(地球起伏/月球起伏)^2/(2*ln(2)^2))`，月球參考依所選地點改變。

缺值特徵不加入計分，但保留完整度標示；這是現有證據的分數，不代表完整測試覆蓋。零值是有效數字。適配度調整資料對計分的貢獻，並非統計信賴區間。新交接資料的特徵分類門檻為：**相似 s≥0.6、不相似 s<0.3，其餘為部分相似**。

任務 ROC 參考權重為 M2=0.183、M3=0.429、M4=0.280、M6=0.108。單項任務排名不混合這些權重；若另算綜合分數，才依所選任務重新正規化。此頁顯示交接資料的 **0–100 分**，與先前的 0–1 顯示尺度分開。M1、M5 不計分。

## 匯入範圍與排名規則

兩個 ZIP 的網站用 JSON 完全相同。新資料包含 **19,599 個陸地格點、4,881 個 MODIS 永久冰雪遮罩格點**、十個月球參考及各任務排名。新候選地排除已知類比區域；M2、M3、M6 沿用每 8° 緯度、25° 經度選一格的規則。相同分數視為同分，沿用來源順序；已知類比地另外列為驗證組，分數可能更高。

M4 提供的細算資料有 151 筆，套用同一冰雪遮罩後有 **135 筆**，其中 **130 筆為新候選地**；最相似與最不相似對照都從可用範圍選出。具名的局部地形驗證點另列，因局部裸露地形可能與周圍一度格點的冰雪狀態不同。全球 M4 網格**只用起伏粗篩**，不能當成坡度與起伏都齊全的細算排名。

保留原始檔與 SHA-256。匯入時將非有限 JSON 值轉為 null，依座標從 CSV 補回省略的原始值，並核對加權計分符合來源的四捨五入精度，最大差異為 0.09 分。沒有執行下載的程式，也不宣稱已獨立驗證全部上游地形與氣候處理；可用 `scripts/import_lunar_handoff.py` 重建。

NASA POWER 是 2001–2025 年、網格約 50 公里的 2 公尺氣溫氣候值，並非地表溫度；12,459 格缺少日溫差。天文計算未納入地形陰影。地球地名是依網格標示的大約位置，實地交通與局部適用性仍需確認。真空、六分之一重力、輻射及帶靜電月塵，仍是這些地球類比無法重現的條件。
