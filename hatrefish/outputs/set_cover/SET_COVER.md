## 4. 限制

- 地點是 0.1° 格（約 11 km），是考察區域，不是確切的測試場地。
- 候選池是每個需求的前 200 名（彼此至少 50 km），不是全球每一格；池外不會被選到。
- 合格規則是設計選擇；敏感度表顯示換門檻後組合變多少。
- 同樣最少地點數的組合可能不只一組；這裡取分數總和最高的那組。
- 選到的兩個地點如果很近，實際上可以算同一趟考察。
